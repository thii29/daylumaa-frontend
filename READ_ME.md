# Daylumaa

## Introduction
- This is a personal management dashboard where users can manage daily, weekly, and monthly tasks, as well as track monthly expenses and budgets.

## Key Features
### Dashboard
- A space to add yearly goals and quickly view daily tasks.
- Year progress bar.
- Heatmap for habit activities and an emotion tracker.
- Chart overviewing monthly savings.
